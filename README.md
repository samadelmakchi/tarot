# فال‌بین ✦ — جامع‌ترین فال‌های آنلاین (PWA)

اپلیکیشن تحت وب فارسی برای همهٔ انواع فال — **راست‌چین، بدون نیاز به بیلد، و کاملاً آفلاین (PWA)**.
هر فال یک **فایل مستقل** است: می‌توانید هر فال را جداگانه ویرایش، حذف یا اضافه کنید بدون آنکه بقیه را خراب کنید.

## امکانات

- **۴۱ فال** در ۱۰ دسته: تاروت (۷ چیدمان)، حافظ، فال روزانه، ورق، اوراکل، رون، عدد و حرف، فنجان و تفاله، بخت و شانس، بدن و چهره، ستاره و برج، طبیعت و عنصرها — مطابق فهرست `فال.md`
- **PWA کامل**: نصب‌پذیر روی موبایل و دسکتاپ، کارکرد **آفلاین** با سرویس‌ورکر
- بدون فریم‌ورک و بدون بیلد (HTML/CSS/JS خالص با ES Modules)
- رابط کاربری شب و طلایی با انیمیشن برگشتن کارت‌ها، چرخ اراکل، شعلهٔ زنده و…
- تاریخ و اعداد شمسی، جستجو، اشتراک‌گذاری و کپی نتیجه

## اجرای محلی

```bash
# بدون وابستگی (فقط Node برای سرور ساده)
npm start            # یا: node scripts/serve.mjs
# سپس: http://localhost:4173
```

> برای تجربهٔ PWA (نصب و آفلاین)، اپ باید از طریق `http://localhost` یا `https://` باز شود، نه `file://`.

## ساختار پروژه

```
index.html             پوستهٔ اصلی (RTL)
manifest.webmanifest   مشخصات PWA
sw.js                  سرویس‌ورکر آفلاین
css/style.css          تم سراسری
js/app.js              مسیریاب و صفحهٔ اصلی
js/registry.js         ثبت‌نام همهٔ فال‌ها
js/lib/                ابزار مشترک (رابط، شانس، تاریخ شمسی، موتور چیدمان تاروت)
js/data/               داده‌های مشترک (دستهٔ ۷۸ تاروت)
js/faals/*.js          ★ یک فایل مستقل برای هر فال
00/                    آیکون‌ها و لوگوی برند شما
assets/icons/          آیکون‌های تولیدشدهٔ PWA
scripts/               سرور محلی و تولید آیکون
```

### هر فایل فال چه شکلی است؟

هر فال در `js/faals/` یک شیء پیش‌فرض صادر می‌کند:

```js
const meta = { id: "uniqu-id", title: "نام فال", emoji: "🔮", category: "دسته",
  categorySlug: "tarot", tagline: "...", blurb: "توضیح کوتاه برای کارت" };

function page(mount) { /* ساخت رابط فال داخل mount */ }

export default { meta, page };
```

### افزودن فال جدید

1. فایلی مثل `js/faals/نام-فال.js` بسازید (قالب بالا).
2. آن را در `js/registry.js` ایمپورت و به لیست `FALS` اضافه کنید.
3. (اختیاری) نام آن را به لیست پیش‌کش در `sw.js` هم اضافه کنید تا از همان ابتدا آفلاین باشد.
4. اگر به دادهٔ دستهٔ تاروت نیاز داشتید، از `js/data/tarot-deck.js` ایمپورت کنید.

برای ساخت رابط سریع می‌توانید از کمکی‌های `js/lib/ui.js` استفاده کنید:
`falPage`، `actionFlow` (دکمهٔ شروع → تأخیر → نتیجه)، `cardSlot`، `readingItem` و…

## محتوا و دقت متون

- **فایل‌های `.txt` و `فال.md`** در ریشه، منبع الهام ساختار بودند؛ متن‌ها (تفسیرها، پیام‌ها، کلیدواژه‌ها) برای این اپ **نوشتهٔ جدید** هستند.
- ابیات حافظ، سعدی، مولانا و فردوسی در «فال حافظ» و «فال کتاب» **مالکیت عمومی** دارند و با نهایت دقت در حفظ املای متن آورده شده‌اند؛ پیش از انتشار رسمی، ابیات را با یک نسخهٔ معتبر چاپی بازبینی کنید.
- فال‌ها «سرگرمی و الهام» هستند، نه پیش‌گویی قطعی؛ چند ماژول (فرنولوژی، ایریدولوژی و…) صراحتاً برچسب «غیرعلمی/نمادین» دارند.
- چند فال (طالع ودیک، هلیوبیوس، کیهان‌شناسی) نسخهٔ **ساده‌شدهٔ نمادین** هستند و در خود صفحه به این نکته اشاره شده است.

## استقرار (Deploy)

کل پوشهٔ پروژه را روی هر هاست استاتیک (Netlify، Vercel، GitHub Pages، Laragon و…) بگذارید؛ مسیر ریشه باید `index.html` را سرو کند. با اولین بازدید، سرویس‌ورکر همهٔ فایل‌ها را کش می‌کند و اپ آفلاین می‌شود.

## تولید دوبارهٔ آیکون

```bash
npm run icons    # بازتولید assets/icons از روی کد
```

برای استفاده از لوگوی برند خودتان کافی است `assets/icons/icon-512.png` و `icon-192.png` را جایگزین کنید و مقادیر `manifest.webmanifest` را حفظ کنید.
