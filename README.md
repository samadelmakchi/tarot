# فال‌بین ✦ — فال‌های تاروت آنلاین (PWA)

اپلیکیشن تحت وب فارسی برای **فال تاروت** — راست‌چین، بدون نیاز به بیلد، و کاملاً آفلاین (PWA).
هر فال یک **فایل مستقل** است: می‌توانید هر فال را جداگانه ویرایش، حذف یا اضافه کنید بدون آنکه بقیه را خراب کنید.

## فال‌ها (۱۵ روش + یک فال ویژه)

**بر اساس دستهٔ کارت:** تاروت کبیر (۲۲ کارت)، تاروت صغیر (۵۶ کارت)، و کل دسته (۷۸ کارت).

**بر اساس تعداد کارت:** ۱ کارتی، ۳ کارتی (گذشته/حال/آینده)، ۴ کارتی هفتگی (موضوع/تمرکز/هشدار/هدیه)، ۶ کارتی (دو لایهٔ سه‌تایی)، ۷ کارتی (شنبه تا جمعه)، ۹ کارتی (ماتریس ۳×۳)، و ۱۰ کارتی (صلیب سلتیک).

**بر اساس موضوع:** عشق و رابطه، شغل و کار، مال و پول، تن و روان، و رشد روحی.

**فال ویژه:** بله/خیر با ۲۲ کارت کبیر.

## امکانات

- **PWA کامل**: نصب‌پذیر روی موبایل و دسکتاپ، کارکرد **آفلاین** با سرویس‌ورکر
- بدون فریم‌ورک و بدون بیلد (HTML/CSS/JS خالص با ES Modules)
- رابط کاربری شب و طلایی با انیمیشن برگشتن کارت‌ها
- تاریخ و اعداد شمسی، اشتراک‌گذاری و کپی نتیجه

## اجرای محلی

```bash
# بدون وابستگی (فقط Node برای سرور ساده)
npm start            # یا: node scripts/serve.mjs
# سپس: http://localhost:4173
```

> برای تجربهٔ PWA (نصب و آفلاین)، اپ باید از طریق `http://localhost` یا `https://` باز شود، نه `file://`.

## ساختار پروژه

```
index.html             پوستهٔ اصلی (RTL)
manifest.webmanifest   مشخصات PWA
sw.js                  سرویس‌ورکر آفلاین
css/style.css          تم سراسری
js/app.js              مسیریاب و صفحهٔ اصلی
js/registry.js         ثبت‌نام همهٔ فال‌ها
js/lib/                ابزار مشترک (رابط، شانس، تاریخ شمسی، موتور چیدمان تاروت)
js/data/               دادهٔ ۷۸ کارت تاروت
js/faals/*.js          ★ فایل‌های مستقل فال تاروت
logo.png, favicon.ico  لوگو و آیکون سایت در روت
00/                    متن‌های منبع فال تاروت
img/                   تصاویر نام‌دار ۷۸ کارت تاروت
scripts/               سرور محلی
```

### هر فایل فال چه شکلی است؟

هر فال در `js/faals/` یک شیء پیش‌فرض صادر می‌کند:

```js
const meta = { id: "uniqu-id", title: "نام فال", emoji: "🔮", category: "دسته",
  categorySlug: "tarot", tagline: "...", blurb: "توضیح کوتاه برای کارت" };

function page(mount) { /* ساخت رابط فال داخل mount */ }

export default { meta, page };
```

### افزودن فال جدید

1. فایلی مثل `js/faals/نام-فال.js` بسازید (قالب بالا).
2. آن را در `js/registry.js` ایمپورت و به لیست `FALS` اضافه کنید.
3. (اختیاری) نام آن را به لیست پیش‌کش در `sw.js` هم اضافه کنید تا از همان ابتدا آفلاین باشد.
4. برای دادهٔ دستهٔ تاروت از `js/data/tarot-deck.js` و برای چیدمان‌ها از `runSpread` در `js/lib/tarot.js` استفاده کنید.

برای ساخت رابط سریع می‌توانید از کمکی‌های `js/lib/ui.js` استفاده کنید:
`falPage`، `actionFlow` (دکمهٔ شروع → تأخیر → نتیجه)، `cardSlot`، `readingItem` و…

## محتوا و دقت متون

- فایل‌های `فال تاروت *.txt` در پوشهٔ `00/` متن‌های منبع چیدمان‌ها هستند؛ تفسیرهای ۷۸ کارت در `js/data/tarot-deck.js` برای این اپ نوشته شده‌اند.
- فال‌ها «سرگرمی و الهام» هستند، نه پیش‌گویی قطعی.

## استقرار (Deploy)

کل پوشهٔ پروژه را روی هر هاست استاتیک (Netlify، Vercel، GitHub Pages، Laragon و…) بگذارید؛ مسیر ریشه باید `index.html` را سرو کند. با اولین بازدید، سرویس‌ورکر همهٔ فایل‌ها را کش می‌کند و اپ آفلاین می‌شود.

### انتشار خودکار روی GitHub Pages

گردش‌کار `.github/workflows/pages.yml` با هر push روی شاخهٔ `main` یا اجرای دستی از تب **Actions**، نحو فایل‌های جاوااسکریپت را بررسی و سایت را منتشر می‌کند. فقط فایل‌های سایت در خروجی انتشار قرار می‌گیرند؛ فایل‌های گیت، اسکریپت‌ها و متن‌های منبع منتشر نمی‌شوند.

در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment**، گزینهٔ **Source** را روی **GitHub Actions** قرار دهید. آدرس سایت این مخزن پس از انتشار موفق:

https://samadelmakchi.github.io/seemorgh-fal/

مسیرهای فایل‌ها، مانیفست و سرویس‌ورکر نسبی هستند و با زیرمسیر مخزن سازگارند؛ نیازی به دامنهٔ اختصاصی یا مرحلهٔ بیلد نیست.

## آیکون‌ها

آیکون برنامه `favicon.ico` و لوگوی هدر `logo.png` در روت پروژه هستند؛ برای تغییر برند همین دو فایل را جایگزین کنید.
